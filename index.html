Outlook OTP Reader

Paste one account line from the sheet — in the format email|password|refresh_token|client_id (or paste the whole row copied from Excel) — and press the button. The newest emails from the Inbox and the Junk folder appear, with any verification code shown big at the top.
For OTP reading please use the OTP Reader program file from the admin - it works on its own. (This web page needs a sign-in helper that is not connected; error AADSTS90023.)
